# Diabetic Retinopathy Detection

Grades diabetic retinopathy severity (0–4) from a retinal fundus photograph using a
Swin Transformer V2 Small fine-tuned on [APTOS 2019](https://www.kaggle.com/c/aptos2019-blindness-detection).

> ⚠️ **Not a medical device.** Student research project, not clinically validated. Nothing it
> outputs is a diagnosis.

Source code: **[github.com/iignlu/Graduation-Project](https://github.com/iignlu/Graduation-Project)**
